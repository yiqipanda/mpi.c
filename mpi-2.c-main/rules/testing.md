# Testing Rules

Every new business logic must be accompanied by tests.

## Requirements
- **Unit Tests:** Mandatory for every use case and domain service.
- **Integration Tests:** Required for repositories and external service adapters.
- **Mocking:** Use mocks for infrastructure dependencies in unit tests.
- **Coverage:** Aim for at least 80% test coverage.
- **Scenarios:** Test edge cases, boundary conditions, and failure scenarios.
- **Clarity:** Tests should serve as documentation for how the code is expected to behave.
